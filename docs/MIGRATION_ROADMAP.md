# 现有修改版 功能移植与多人同步任务清单

这是 RWmiao 的长期任务清单。任何功能只有通过对应的多人同步门禁，才可标记为完成。

## 多人同步规则

1. **纯绘制功能**只能读取已同步的游戏状态，不得修改模拟对象、命令队列、随机数、寻路状态、战争迷雾、经济或单位指令。
2. **指令类功能**必须走游戏原生同步命令/网络包路径；多人游戏中禁止直接写入单位、队伍、队列、路径、目标或资源字段。
3. **确定性功能**必须在相同同步输入下生成完全相同的命令序列；本地时间、帧率、UI 顺序、哈希迭代顺序和未同步设置不得影响模拟。
4. 未通过门禁的功能不得作为“已移植”功能进入发布版；最终实现必须在联网对局可用，不能以永久禁用多人模式代替同步设计。
5. 门禁证据必须包含主机/客户端日志、命令序列对比、无不同步警告，以及干净对局的录像或状态复核。

## 单项功能多人验收流程

- [ ] 主机与客户端使用一致的游戏、模组和 RWmiao APK。
- [ ] 先记录功能关闭时的基线。
- [ ] 每次只启用一个功能、只改变一个设置。
- [ ] 对比命令类型、所有者、目标、坐标和模拟 Tick。
- [ ] 持续运行一段对局并完成保存/录像复核，确认无不同步。
- [ ] 支持时进行重连/重新进入测试。
- [ ] 记录 APK SHA-256、游戏版本、设置、日志和结论。
