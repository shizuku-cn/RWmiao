# 房主游戏选项扩展 p8

## 结论

### 被 Ban 单位显示 `locked`

在“所有玩家都包括未修改原版客户端”的条件下不可行。原版客户端的动作锁定状态
由本地动作/单位规则计算，原版网络包不会携带任意 Ban 单位集合；房主不能让未修改
客户端凭空获得这份列表。仅对安装模块的客户端做 UI Hook 可以显示 locked，但不满足
全体玩家要求，因此 p8 不实现该部分。

### Ban 提示文字

可行。房主收到被 Ban 的命令后，原版服务器会广播
`desync:Skipped command issued from server`。p8 在该广播前拦截，仅针对本次被 Ban
命令改为广播：

`desync：此服务器已拉黑该单位`

这是网络层消息，不依赖客户端安装模块，未修改客户端也能显示替换后的文本。

## 实现边界

- 只有 Ban 命令触发替换，不改写其他真正的 desync 错误。
- Ban 仍由房主端 `e.i()`/`e.h()` 和生产队列 Hook 执行权威拦截。
- 尚未进行真机多人验证；应使用一名房主和一名未修改客户端确认建造/生产失败及提示文本。
